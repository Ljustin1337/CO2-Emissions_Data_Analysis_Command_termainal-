Dataset: OWID CO2 and Greenhouse Gas Emissions data 

Executive Summary
This assessment determines whether the raw 2022 CO2 emissions dataset is reliable enough to base decisions on. The dataset was well-structured and organized, but some key values were missing, including 89 GDP values and 36 ISO codes. The biggest issue is the missing GDP values. If we adjust how we tackle climate change using incomplete data, anomalies might occur, such as some countries not getting the help they need. If possible, we should send a team to collect the missing data before worldwide funding begins. My comparison of the USA and Thailand baselines shows a critical disparity for a highly vulnerable country like Thailand. Countries with lower GDPs often face a disproportionate CO2 impact. We should focus on vulnerable countries like Thailand rather than thriving countries that generate higher pollution rates. When auditing the database, we used command-line tools to inspect the data while leaving the raw file untouched. We refined our searches so that irrelevant values could be ignored. We were able to target the exact missing GDP values before proceeding to the next steps. For our final checks, we manually verified the missing values in the data baseline before getting the assistance of AI, as this was the best way to avoid discrepancies.
